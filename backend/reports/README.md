# reports/

Generated evaluation and cost-benchmark results from the `scripts/` tooling.
These are regenerated by re-running the scripts; the committed copies are the
ones referenced from the project `README.md` / `docs/EVALUATION.md`.

| File | Produced by |
|---|---|
| `eval_cardd_results.json` / `eval_cardd_report.md` | `scripts/eval/run.py` |
| `openai_cost_results.json` | `scripts/cost/run_openai.py` |
| `cost_comparison.json` / `cost_benchmark_report.md` | `scripts/cost/compare.py` |

`*.log` files here are git-ignored.
